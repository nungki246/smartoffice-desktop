# SmartOffice Desktop

Aplikasi desktop modular untuk SIMRS (Sistem Informasi Manajemen Rumah Sakit).

## Unduh / Update

- Instalasi: unduh installer dari rilis terbaru pada tab **Releases**.
- Update otomatis: di aplikasi, menu **Alat -> Periksa Pembaruan** (memerlukan koneksi internet dan repo ini public).

## Modul

- Dashboard (ringkasan pasien dan grafik pendaftaran)
- Pendaftaran (registrasi pasien dan pelayanan)
- Perawat (asuhan keperawatan dan tindakan)
- Pegawai (data pegawai dan sumber daya manusia)
- Hak Akses (manajemen peran dan hak akses)
- Manajemen Aplikasi (kelola daftar aplikasi)
- Pengaturan (konfigurasi koneksi database)

## Teknologi

- Windows (Lazarus / Free Pascal)
- Database: PostgreSQL / SQLite
- Arsitektur modular / plugin
